## ⚡ Core Features

- **Google & Stripe Inspired Aesthetic**: Modern dark/light/system theme provider with smooth backdrop blur, glowing gradient cards, and particle canvas animations.
- **Global Command Palette (`Ctrl+K` / `⌘K`)**: Instant fuzzy search across projects, research papers, skills, technical blog posts, and 20+ verified social handles.
- **Engineered Systems Showcase**:
  - 🤖 **NEON AI Operating System**: Autonomous local-first agentic OS with voice pipeline, vector memory engine, and system tool calling.
  - 🛡️ **SafeNet Android App**: Privacy-first offline security platform with local VPN, DNS-over-HTTPS filtering, and TensorFlow Lite anomaly detection.
  - 📡 **DAAS-V2V Architecture**: Density-Aware Adaptive Secure Vehicle-to-Vehicle communication system for Intelligent Transportation Networks.
  - 🎙️ **AI Voice Forensics**: Deepfake speech detection & mel-spectrogram analysis engine.
- **Academic Research Hub**: IEEE paper draft abstracts, mathematical model breakdowns, and patent concept highlights with citation copy utility.
- **GitHub Contribution Dashboard**: Simulated contribution heatmap grid, language distribution ratio, and pinned repository cards.
- **Centralized Social Presence**: 20+ verified academic, competitive coding, and social profiles (GitHub, LinkedIn, ResearchGate, Google Scholar, ORCID, LeetCode, Kaggle, etc.).
- **ATS Interactive Resume**: Embedded CV document viewer with instant print / PDF download.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Berry1924/my-portfolio.git
   cd my-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
